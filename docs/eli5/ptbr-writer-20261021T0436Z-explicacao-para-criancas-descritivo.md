# O que o ptbr-writer faz

## O ajudante de textos

O ptbr-writer é um ajudante. Ele lê um texto em português e escreve o texto de novo. O texto novo fica mais fácil de entender.

Pense num quarto bagunçado. Os brinquedos estão todos lá, mas você não acha nada. O ptbr-writer arruma o quarto. Ele não joga brinquedo fora e não compra brinquedo novo. Ele só coloca cada brinquedo no lugar certo.

## As regras do ajudante

O ptbr-writer segue regras simples. Cada regra deixa o texto mais claro.

1. **Quem faz aparece.** A frase diz quem faz a coisa. "O João chutou a bola" é melhor que "a bola foi chutada".
2. **Uma ideia por frase.** Uma frase conta uma coisa só. Duas coisas viram duas frases.
3. **Palavra certa para a ação.** "Validar" é melhor que "realizar a validação". A palavra curta diz a mesma coisa.
4. **Um nome para cada coisa.** Se o texto chama o cachorro de "Rex", o texto chama o cachorro de "Rex" até o fim.
5. **Número de verdade.** O texto diz "3 maçãs", e não "algumas maçãs".
6. **Palavras escritas do jeito certo.** O ptbr-writer usa a ortografia do Brasil de hoje.

## Os jeitos de arrumar

O ptbr-writer tem jeitos diferentes de arrumar. Cada jeito serve para um tipo de texto. Esses jeitos têm o nome de "níveis".

- **Estrito:** para instruções passo a passo, como a receita de um bolo. Nenhum passo pode ficar confuso.
- **Descritivo:** para explicar como uma coisa funciona, como este texto.
- **Leve:** para recados entre colegas.
- **Científico:** para textos de cientista. Cada frase mostra de onde veio a informação.
- **Smart-note:** para bilhetes curtos. Cada bilhete guarda uma ideia só.

## O que o ajudante não faz

O ptbr-writer não inventa nada. Ele não muda a opinião de quem escreveu o texto. Quando ele não sabe se uma coisa é verdade, ele coloca um sinal de aviso (⚠). Depois, uma pessoa confere.

## Resumo

O ptbr-writer pega um texto difícil e devolve um texto fácil. O texto novo diz as mesmas coisas, com palavras mais claras.
