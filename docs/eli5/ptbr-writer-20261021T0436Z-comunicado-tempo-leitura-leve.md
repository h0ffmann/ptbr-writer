# Novidade no ptbr-writer: tempo de leitura estimado

A partir da próxima versão, o ptbr-writer mostra o tempo de leitura estimado em todo texto que gera.

O plugin coloca uma linha no início de cada arquivo `.md` e `.txt`. O PDF repete a linha do `.md`. A linha tem este formato:

`Leitura estimada: ~2 min (450 palavras, 3 links, 1 bloco de código)`

O plugin calcula o tempo com um script, a partir das palavras, dos links e dos blocos de código do texto. Você não precisa configurar nada.

Dúvidas ou sugestões? Fale com a equipe do plugin.
